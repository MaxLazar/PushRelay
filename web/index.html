📡 Flash PushRelay

Install the PushRelay firmware onto an ESP32 straight from your browser — no software to install.

This browser can't flash.

Web Serial is only available in Chrome, Edge, or another Chromium-based desktop browser. Open this page there and try again.

ESP32-DevKitC / WROVER, 8 MB flash
How to flash
  1. Connect the ESP32 to your computer with a USB cable.
  2. Click Connect above and pick the serial port (CP2102 / USB Serial; on Windows it may be COMx).
  3. Choose Install PushRelay and confirm the erase prompt. Flashing takes ~1 minute.
  4. When it finishes, the ESP32 reboots and starts the PushRelay-Setup Wi-Fi hotspot — connect to it to configure Wi-Fi and your delivery provider.

A fresh, never-flashed ESP32 works fine — the chip's built-in ROM bootloader handles the first flash. If Connect can't find a port, install the CP210x USB-UART driver (rarely needed on modern Windows/macOS/Linux).
